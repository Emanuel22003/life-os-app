Install LIFE/OS

It takes one minute. LIFE/OS then opens like a normal app, works without internet, and updates by itself.

emanuel22003.github.io/life-os-app Open LIFE/OS

One link is all you need. Open it on your phone and LIFE/OS shows you these steps itself, then sets you up. This page is here if you want pictures, or to set up Sync.

Make a GitHub account (for Sync)

Only needed if you want LIFE/OS the same on your phone and your computer. GitHub is free; your LIFE/OS data goes into a private folder there (a “repository”) that only you can see.

  1. Go to github.com/signup

    github.com/signup — on your computer is easiest.

  2. Type your email, a password and a username

    Click Continue after each one. The username can be anything (it's not shown in LIFE/OS).

    GitHub sends a code to your email to make sure it's you.

    If GitHub asks about your team or interests, you can skip. Free is all you need.

Sync your phone and computer

Do this once on your first device, then once on every other device. You need to be signed in to GitHub in the same browser.

On your first device

  1. Open Sync in LIFE/OS

    Settings → Sync & backup → Open Sync. (On a computer you can also click the line at the bottom of the menu that says how your data is saved.)

  2. Step 1: create your private repository

    Click New repository on GitHub. The name life-os-data and Private are already filled in. Click Create repository, then come back to LIFE/OS.

    Click New key on GitHub. Almost everything is filled in. Under Repository access choose Only select repositories and pick life-os-data. Then click Generate token at the bottom.

  4. Copy the key

    GitHub shows a long key that starts with github_pat_. Click the copy button next to it. It's shown only once — if you lose it, just make a new one.

  5. Step 3: paste it in LIFE/OS and click Connect

    Back in the Sync window, paste the key and click Connect. The line at the bottom of the menu now says Synced · just now.

On every other device

  1. Install LIFE/OS there and open Sync

    Same as above: Settings → Sync & backup → Open Sync.

  2. Skip step 1, make a new key (step 2)

    Your repository already exists. Make a new key for this device the same way (Only select repositories → life-os-data → Generate token) and copy it.

  3. Paste and Connect

    If this device already has things in it, LIFE/OS asks what to do. Pick Combine both: nothing is lost. On a fresh device it just downloads everything.

Keep your key secret. Never send it to anyone (not even me). It only opens your life-os-data repository and lasts a year; when it runs out, LIFE/OS says “Sync key expired” and you make a new one the same way.

Good to know

  • Your data stays on your device. No account, no tracking. With Sync on, it also goes to your own private GitHub repository — nowhere else.
  • Updates come by themselves. When there's a new version you'll see “LIFE/OS … is ready · Reload”.
  • Make a backup now and then: Settings → Download a backup. If you delete the app or clear your browser, the data on that device is gone.
  • Pick your tabs: More → Edit tabs.
