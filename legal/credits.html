Typefaces

Icons

The icons in the app are small line drawings written as SVG in LIFE/OS's own code; no icon library or icon font is loaded. Many of the basic ones, such as plus, minus, check, close, the arrows and chevrons, the pencil, the lightning bolt, the moon and the sun, have the same or nearly the same shapes as icons in two open-source icon sets: Feather (MIT License) and Lucide (ISC License). Code

LIFE/OS is written from scratch in plain HTML, CSS and JavaScript. It contains no third-party libraries, frameworks, SDKs, analytics, advertising or tracking code (the icon shapes above are drawing data, not code that runs). Sync talks to GitHub's public API with your own key; no GitHub code runs in the app.
